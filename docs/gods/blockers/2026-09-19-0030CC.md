# Assignment: `0030CC`, the object table update (supervisor, 19 September)

The creature subsystem is closed end to end (`00A578` → `00A772` → every
kind handler and callee, 19 September).  The tick's largest phase by
instructions (`docs/gods/tick-map.md`: ~1,410 per tick) is `0030CC`, read

## Shape

1. **Phase counters** (`0030CC`–`003138`): `F260`/`F388`/`F250` cleared,
   `F262` set to the list head `FF0BF8`; when `EF4A` is clear, `F252` counts
   mod 32 and `F206` mod 5; when `EF4C` is clear, `F258` and `F254` mod 4,
   `F256` mod 6, `F204` mod 7 — the world's animation phases, RAM only.
2. **The object table scan** (`00313A`–`00315C`): 200 entries of 8 bytes
   at `FF4342` (`game.movement.BOX_SCAN_TABLE` — the placed objects of the
   level; its role here is the object record: `+0` x, `+2` y, `+4` a
   signed word whose negative means inactive, `+6` a non-zero-when-live
   word) with a parallel byte per entry at `FF3FEA` (the object's phase);
   an entry with `+6 ≠ 0` and `+4 ≥ 0` runs the body.  Most of the 1,410
   instructions are this scan (seven per slot); the bodies are the
   semantics.
3. **The per-object body** (`003186` →): saves the entry in `F1DE`; a
   negative phase byte skips (`0031E4`); phase `0x18` is a terminal
   (`0031E2`); otherwise two ROM tables indexed by the phase — `0033D4`, a
   per-phase delta added to `+2(a0)` (the object's y), and `0033EC`, a
   per-phase sound cue: when non-zero, `FDF4 ← cue + 0x3E` (**a sound
   request**, the world's own); the phase increments, clamped at `0x25`;
   then `003284` (not read here) with the entry's x/y in `d0`/`d1`.
4. **The tail** (`003160`–`003184`): `F388` → `F260`; when `F250` is set,
   `EECD` clear and `F216` clear, `FDF4 ← 0x33` (a second sound request).

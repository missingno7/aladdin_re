# Frozen historical evidence

Files in this directory preserve milestone reports from the pre-history
snapshot/replay workflow.  They retain ROM maps, measurements, recorded versus
constructed coverage, and recovery decisions at their original source freeze.

They are evidence, not current operating instructions.  The present player and
verification commands use immutable cold-start input histories and do not
promise to load legacy `.alreplay` or `.alsnap` artifacts.  See
[../history.md](../history.md) for the current model.
